01 — The problem

Workflow tools tell you about a delay after it's already happened

Food processing runs on perishable inputs and strict compliance windows, yet most deployed systems remain reactive — managers act under time pressure instead of ahead of it, and no existing platform ties deadline risk, task scheduling, and workforce competency into one loop.

02 — The system

Three components, one continuous feedback loop

Each module runs as an independent Python/Flask microservice, exchanging state through a shared Firebase Realtime Database — so a risk score, a schedule change, or a skill update anywhere in the loop reshapes the other two.

COMPONENT 01 · DEADLINE RISK

Adaptive Deadline Risk Predictor

K.S.S. RajapakshaIT22296382

Frames deadline risk as three-class classification (Low / Medium / High) over six order attributes plus three engineered features — Workload Ratio, Machine Pressure, and Delay Propensity. A Random Forest ensemble runs against a Logistic Regression baseline, with SMOTE balancing and five-fold stratified cross-validation. Predictions below a 0.75 confidence threshold are routed to a human for review rather than triggering automatic action.

  • ModelRandom Forest, 200 trees
  • BaselineLogistic Regression (L2)
  • Class balancingSMOTE
  • Confidence gate0.75 → human review
  • Projected accuracy≥ 88%
  • High-risk recall≥ 91%
COMPONENT 02 · TASK SCHEDULING

Smart Task Management System

Y.S. RathnayakeIT22917652

A two-stage hybrid prioritization engine: a rule-based score (urgency, importance, dependency weight, risk score) is refined by a Random Forest regression adjustment. Google OR-Tools' CP-SAT solver then schedules under precedence, resource, deadline, and skill-readiness constraints within a 10-second budget per cycle, re-triggered automatically on any high-risk classification, delay, or manual override.

  • Stage 1Rule-based Srule
  • Stage 2RF regression ΔSML, λ = 0.4
  • SolverOR-Tools CP-SAT, 10s budget
  • Tie-break ruleMinimize worker skill gap
  • Tardiness vs FIFO−22.4%
  • Resource utilization67% → 81%
COMPONENT 03 · WORKFORCE SKILL

Adaptive Skill Development Tracker

K.Y.H. DalpathaduIT22026002

Maps O*NET 28.0 competency descriptors augmented with HACCP, GMP, ISO 22000, and BRCGS requirements into a Role Competency Matrix. Employee gaps are scored, classified as low / moderate / critical, and a hybrid recommender — cosine-similarity content filtering blended with peer-based collaborative filtering — generates personalized micro-learning pathways that feed skill-readiness scores straight back into task scheduling.

  • Gap scoreG(e,c) = max(0, RCM − Skill)
  • Gap classifierRandom Forest
  • Recommender0.55·CBF + 0.45·CF
  • Standards mappedHACCP, GMP, ISO 22000, BRCGS
  • Gap F1-score≥ 0.87
  • Recommendation nDCG@50.83 (+14%)
03 — Architecture

Four layers, loosely coupled by design

Any single module can fail without taking the others down with it — every hand-off happens through the shared data store, not a direct call.

Data Ingestion
Orders, task & HR records, and the O*NET Web Services API feeding raw operational data into the pipeline.
Intelligence Layer
The three components above, running as independent microservices in a continuous feedback loop.
Cloud Persistence
Firebase Realtime Database, RBAC-secured, mediating every hand-off between modules.
Presentation Layer
Role-specific React.js dashboards for Employee, Supervisor, HR, Production Manager, and Admin.
HTTPS / TLS AES-256 at rest JWT authentication Role-based access control Auditable reschedule logs
